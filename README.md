# VELTRIX STUDIO — ربات تبلیغات ۲۴/۷ (veltrix-ads)

ربات جداگانهٔ تبلیغات و جذب مشتری. کاملاً مستقل از ربات اصلی (`veltrix-bot`)
اجرا می‌شود و سه کار انجام می‌دهد:

1. **پست خودکار تبلیغاتی** — هر ۳ ساعت (قابل تنظیم) یک پست تبلیغاتی متفاوت
   از ۱۲ کمپین آماده، در کانال منتشر می‌کند؛ هر پست دکمهٔ «ثبت سفارش» با
   لینک ردیابی‌دار به ربات اصلی دارد.
2. **پیام همگانی (Broadcast)** — پنل ادمین با `/broadcast` به همهٔ مشترکینِ
   رباتِ تبلیغات پیام می‌فرستد (با پیش‌نمایش و تأیید).
3. **ردیابی جذب مشتری** — هر کلیک روی دکمه‌های تبلیغ، با payload مثل
   `ads_5` وارد ربات اصلی می‌شود؛ آنجا با `/refstats` می‌بینی هر کمپین چند
   لید آورده و مدیر با اعلان آنی از هر لید جدید خبردار می‌شود.

> ⚠️ این ربات **اسپم نمی‌کند** — پیام ناخواسته به غریبه‌ها ربات را بن می‌کند.
> تبلیغ فقط در کانال خودت، گروه‌های خودت و برای مشترکینِ اختیاری ارسال می‌شود.

## راه‌اندازی سریع

### ۱. ساخت ربات در BotFather

1. توی تلگرام به [@BotFather](https://t.me/BotFather) پیام بده.
2. `/newbot` → اسم: `VELTRIX STUDIO Ads` → یوزرنیم: مثلاً `VeltrixAds_bot`.
3. توکن را کپی کن (شکل `123456:AA...`).

### ۲. ادمین‌کردن ربات در کانال

ربات جدید را به‌عنوان **ادمین** کانال `@VeeltrixStudio` اضافه کن (دسترسی
پست‌گذاری لازم دارد).

### ۳. دیپلوی روی Render

1. این پوشه را به یک مخزن GitHub جداگانه (مثلاً `veltrix-ads`) push کن.
2. داشبورد Render → **New + → Blueprint** → مخزن `veltrix-ads`.
3. مقدار `ADS_BOT_TOKEN` را وارد کن → **Apply**.
4. بعد از سبز شدن، تب Logs باید این را نشان دهد:
   ```
   [ads] @VeltrixAds_bot is up and running.
   ```
5. اگر آدرس سرویس با `veltrix-ads.onrender.com` فرق داشت، URL را در
   `.github/workflows/keep-alive.yml` اصلاح کن (مانند ربات اصلی، یک workflow
   پینگ ۲۴/۷ هم اینجا فعال است).

## تنظیمات (.env)

| متغیر | پیش‌فرض | توضیح |
| --- | --- | --- |
| `ADS_BOT_TOKEN` | — | توکن ربات تبلیغات (اجباری) |
| `ADMIN_TELEGRAM_IDS` | — | شناسهٔ ادمین‌ها |
| `ADS_CHANNEL_ID` | `@VeeltrixStudio` | کانال انتشار تبلیغات |
| `ADS_INTERVAL_MINUTES` | `180` | فاصلهٔ پست‌های خودکار (دقیقه) |
| `MAIN_BOT_USERNAME` | `VeltrixStudio_bot` | ربات اصلی برای هدایت مشتری |
| `SITE_URL` | veltrixstudio.com | دکمهٔ سایت در پست‌ها |

## دستورهای ادمین

| دستور | کار |
| --- | --- |
| `/ads_status` | وضعیت کامل تبلیغات |
| `/ads_on` / `/ads_off` | خاموش/روشن‌کردن پست خودکار |
| `/ads_now` | ارسال فوری پست بعدی |
| `/ads_list` | فهرست ۱۲ کمپین آماده |
| `/ads_post ads_5` | ارسال یک کمپین خاص |
| `/ads_skip` | ردکردن پست بعدی |
| `/ads_set 120` | تغییر فاصلهٔ پست‌ها (دقیقه یا مثل `2h`) |
| `/broadcast متن` | پیام همگانی به مشترکین (با تأیید) |
| `/stats` | آمار مشترکین و پست‌ها |

در ربات اصلی هم: `/refstats` — تعداد لیدِ هر کمپین تبلیغاتی.

## نکتهٔ پلن Free

پلن Free رندر دیسک ندارد؛ لیست مشترکین و وضعیت چرخش پست‌ها با هر دیپلوی ریست
می‌شود (خودِ پست‌گذاری مشکلی ندارد). برای نگهداری دائمی لیست مشترکین، پلن
Starter + Disk 1GB لازم است.
