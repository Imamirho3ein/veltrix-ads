# VELTRIX STUDIO — ربات تبلیغات ۲۴/۷ (veltrix-ads)

ربات جداگانهٔ تبلیغات و جذب مشتری. کاملاً مستقل از ربات اصلی (`veltrix-bot`)
اجرا می‌شود و این کارها را انجام می‌دهد:

1. **پست خودکار در کانال‌ها و گروه‌ها** — هر ۳ ساعت (قابل تنظیم) یک پست از
   ۱۲ کمپین آماده در همهٔ تارگت‌های ثبت‌شده منتشر می‌کند. کانال اصلی با
   `ADS_CHANNEL_ID` تنظیم می‌شود؛ **هر کانال/گروهی که ربات را در آن ادمین
   کنید، خودکار ثبت می‌شود** و تبلیغ آنجا هم ارسال می‌شود.
2. **تبلیغ پیوی (DM)** — هر کاربری که ربات را `/start` کند فوراً یک پیام
   تبلیغاتی جذاب می‌گیرد و به‌صورت دوره‌ای (پیش‌فرض روزانه) کمپین تبلیغاتی
   به همهٔ مشترکین ارسال می‌شود.
3. **پیام همگانی دلخواه** — `/broadcast متن` با پیش‌نمایش و تأیید.
4. **ردیابی جذب مشتری** — هر کلیک روی دکمه‌ها با payload مثل `ads_5` وارد
   ربات اصلی می‌شود؛ با `/refstats` عملکرد هر کمپین را می‌بینید و هر لید
   جدید اعلان آنی می‌دهد.

> ⚠️ محدودیت واقعی تلگرام: ربات‌ها فقط به کسانی که `/start` زده‌اند می‌توانند
> پیام بدهند و پست‌گذاری در کانال/گروه دیگران فقط با ادمین‌بودن ممکن است.
> این ربات اسپم نمی‌کند — تبلیغ فقط در کانال/گروه‌های خودتان و برای مشترکینِ
> اختیاری است.

## راه‌اندازی سریع

### ۱. ربات را ادمین کانال/گروه‌های خود کنید

ربات را در کانال اصلی و هر کانال یا گروه دیگری که می‌خواهید تبلیغ بشود،
**ادمین** کنید. با اولین پیام از تلگرام (`my_chat_member`)، آن چت خودکار به
لیست تارگت‌ها اضافه می‌شود — نیازی به دستور نیست.

### ۲. دیپلوی روی Render

1. داشبورد Render → **New + → Blueprint** → مخزن `veltrix-ads`.
2. مقدار `ADS_BOT_TOKEN` را وارد کنید → **Apply**.
3. لاگ باید نشان دهد: `[ads] @VeltrixStudioAds_bot is up and running.`
4. اگر آدرس سرویس با `veltrix-ads.onrender.com` فرق داشت، URL را در
   `.github/workflows/keep-alive.yml` اصلاح کنید.

## تنظیمات (.env)

| متغیر | پیش‌فرض | توضیح |
| --- | --- | --- |
| `ADS_BOT_TOKEN` | — | توکن ربات تبلیغات (اجباری) |
| `ADMIN_TELEGRAM_IDS` | — | شناسهٔ ادمین‌ها |
| `ADS_CHANNEL_ID` | `@VeeltrixStudio` | کانال اصلی انتشار |
| `ADS_INTERVAL_MINUTES` | `180` | فاصلهٔ پست‌های خودکار (دقیقه) |
| `ADS_DM_INTERVAL_MINUTES` | `1440` | فاصلهٔ کمپین پیوی (دقیقه) |
| `MAIN_BOT_USERNAME` | `VeltrixStudio_bot` | ربات اصلی برای هدایت مشتری |

## دستورهای ادمین

| دستور | کار |
| --- | --- |
| `/ads_status` | وضعیت کامل تبلیغات |
| `/ads_on` / `/ads_off` | خاموش/روشن‌کردن پست خودکار |
| `/ads_now` | ارسال فوری پست بعدی به همهٔ تارگت‌ها |
| `/ads_list` | فهرست ۱۲ کمپین آماده |
| `/ads_post ads_5` | ارسال یک کمپین خاص |
| `/ads_set 120` | تغییر فاصلهٔ پست‌ها (دقیقه یا مثل `2h`) |
| `/ads_targets` | فهرست کانال‌ها و گروه‌های ثبت‌شده |
| `/ads_addtarget @name` | افزودن دستی تارگت |
| `/ads_removetarget @name` | حذف تارگت |
| `/ads_dm_on` / `/ads_dm_off` | کمپین پیوی به مشترکین |
| `/ads_dm_set 720` | فاصلهٔ کمپین پیوی |
| `/ads_dm_now` | ارسال فوری کمپین پیوی |
| `/broadcast متن` | پیام دلخواه به مشترکین |
| `/stats` | آمار مشترکین و پست‌ها |

در ربات اصلی: `/refstats` — تعداد لیدِ هر کمپین.

## نکتهٔ پلن Free

پلن Free دیسک ندارد؛ لیست مشترکین و تارگت‌ها با هر دیپلوی ریست می‌شود (کانال
اصلی از env همیشه می‌ماند). برای ماندگاری، پلن Starter + Disk 1GB لازم است.
